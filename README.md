      Random Number Generator

     This is a simple Windows Forms application written in C that generates unique random numbers based on user input.

      Features
     - Generates random numbers between 1 and a user-defined maximum.
     - Ensures no duplicate numbers are generated.
     - Clean and user-friendly interface.

      How to Use
     1. Enter the maximum number in the text box.
     2. Click the "Generate" button to get a random number.
     3. Repeat until all numbers are generated.
